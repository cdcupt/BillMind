BillMind · First-Launch Privacy Notice · Worker deliverable

Welcome notice

A one-time, informational privacy notice shown on the very first launch. It explains BillMind's local-first posture and links the full policy. It does not gate anything — AI data sharing keeps its own separate consent.

shows once, first launch only flag UserDefaults — no schema change gates nothing (informational)

1Behavior

  • On launch, if UserDefaults.standard.bool(forKey: "hasSeenFirstLaunchNotice") is false, present the notice as a sheet over the root (ContentView).
  • Tapping Get started sets the flag true and dismisses. It never appears again.
  • Purely informational — it does not block recording or viewing, and it does not grant AI consent. the new hasSeenFirstLaunchNotice flag ≠ hasConsentedToAIDataSharing; the AI consent sheet still appears before the first AI call, unchanged.

2Storage — no schema change

The "seen" flag lives in UserDefaults, not the SwiftData AppSettings model. A UI-only flag doesn't belong in the persistent store, and keeping it out means no SchemaV2 / migration — consistent with the Record tab v1.

3Copy (honest to actual behavior)

  • Title: "Welcome to BillMind"
  • 🔒 "Your journals and bills stay on this device. BillMind has no servers and no account."
  • ✨ "AI receipt recognition sends a photo to your chosen provider — and only after you agree, the first time."
  • 🗂 "Delete any journal or bill anytime, right inside the app." (honest: Settings only backs up config/API keys, not bills; there is no delete-all — deletion is per-journal/per-bill.)
  • Link: "Read the Privacy Policy" → https://cdcupt.github.io/BillMind/docs/privacy-policy.html (opens in Safari)
  • Button: "Get started"

4Presentation

  • SwiftUI .sheet bound to @State private var showWelcome in ContentView, set in .onAppear from the UserDefaults flag.
  • New file BillMind/Views/Onboarding/WelcomeNoticeView.swift (the sheet body). Uses SketchTheme + an AI-generated mascot, matching the app.
  • Not dismissible by swipe-to-cancel into a half state — only "Get started" sets the flag (interactive-dismiss disabled so the flag is always written).

5E2E interaction (important)

  • --uitesting-reset is extended to also set hasSeenFirstLaunchNotice = true, so the existing create-journal/add-bill E2E and the Record-tab E2E start without the notice and are not derailed.
  • A dedicated test passes a new --uitesting-show-notice arg (clears the flag) to assert the notice appears once: launch → "Welcome to BillMind" visible → tap "Get started" → relaunch (flag now set) → notice does not appear.

6Definition of done

  • Notice shows on first launch only; "Get started" sets the UserDefaults flag.
  • No SwiftData schema change; AI consent flow unchanged and still separate.
  • Privacy Policy link opens the live Pages URL.
  • E2E: notice appears once then never again; existing + Record E2Es unaffected (reset arg skips it).
  • Screenshot captured of the notice.
